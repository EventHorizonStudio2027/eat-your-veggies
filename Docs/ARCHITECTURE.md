# Technical architecture

Unity 6 / C#; offline-first and content-driven.

- Core: app lifecycle and scene navigation.
- Profiles: versioned local child profiles and avatar selections.
- Adventure: quest catalog, branching steps, checkpoints.
- Parent: protected settings, optional food discovery journal.
- UI: calm large-touch-target child HUD; separate parent dashboard.
- Content: authored vegetable worlds and mini-games.

First milestone: Broccoli Forest vertical slice. No backend required.
